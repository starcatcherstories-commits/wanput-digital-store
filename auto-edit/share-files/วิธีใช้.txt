Auto Edit — ตัดเงียบ ตัดพูดซ้ำ/เอ่ออ่า ใส่ซับไทย อัตโนมัติ (ฟรี ทำในเครื่อง)

ติดตั้ง (ครั้งเดียว)
1. แตกไฟล์ zip ไว้ที่ไหนก็ได้ (ห้ามไว้ในโฟลเดอร์ Downloads ชั่วคราว)
2. ดับเบิลคลิก Install-Autostart.cmd
   (ถ้า Windows เตือน กด More info > Run anyway)

ใช้งาน
1. ใส่คลิปในโฟลเดอร์ input (ใส่ทีละ 100 คลิปก็ได้)
2. รอ ผลงานอยู่ที่ output\พร้อมใช้

ต้องการ: Windows 10/11, RAM 8GB ขึ้นไป
คลิปละประมาณหลายนาที ขึ้นกับความเร็วคอม
ปิดโปรแกรม: ดับเบิลคลิก Stop-Auto-Edit.cmd
